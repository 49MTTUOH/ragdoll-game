# Ragdoll Duel — MVP

Простой рабочий MVP локальной дуэли 1 на 1 на одном экране. Сделан для показа преподавателю.

## Описание

- Человекоподобный упрощённый ragdoll (торс, таз, голова, руки, бёдра, голени, стопы) на физике Matter.js
- Отключён сон физики (`enableSleeping: false`) — персонажи чётко реагируют на управление
- Мяч, ворота, счёт, таймер 60 секунд
- Управление на одном клавиатурном экране
- HTML5 Canvas + Matter.js, без сборки

## Управление

| Игрок | Кнопки |
|---|---|
| **Игрок 1** | `W`, `A`, `D` |
| **Игрок 2** | `←`, `↑`, `→` |

## Как запустить

Открыть `index.html` в браузере. Нажать `SPACE` для старта.

## Пояснения по MVP

- Суставы имеют небольшие угловые лимиты — конечности не выворачиваются неестественно
- Прыжок срабатывает, когда стопы/голени достаточно близко к земле
- Сила хода и прыжка немного подкручены для ощущения «бега/пинка»
- Рагдоллы не сталкиваются между собой (внутренняя группа), меньше запутываются
