# Ragdoll Duel

Физическая 2D-игра для двух игроков на одном экране.

## Что это за игра?

Аркадный футбол с ragdoll-персонажами. Два игрока управляют физическими фигурками на зелёном поле и пытаются забить мяч в ворота соперника. Физика делает движения непредсказуемыми и весёлыми.

## Как управлять?

### Игрок 1 (Синий)
- **W** — прыжок
- **A** — влево
- **D** — вправо

### Игрок 2 (Красный)
- **↑** — прыжок
- **←** — влево
- **→** — вправо

### Общее
- **Пробел** — начать игру

## Что должен делать игрок?

1. Управлять своим персонажем
2. Пинать мяч в ворота противника
3. Забить больше голов за 60 секунд
4. Победить соперника

## Что пока не реализовано?

- Мобильное управление (только клавиатура)
- Звуковые эффекты
- Анимации голов и побед
- Настройка времени матча
- Различные режимы игры

## Технологии

- TypeScript
- Vite
- Matter.js (физика)
- HTML5 Canvas
