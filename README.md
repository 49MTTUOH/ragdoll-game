# Ragdoll Duel

Физическая 2D-игра для двух игроков на одном экране.

## Что это за игра?

Аркадный футбол с ragdoll-персонажами. Два игрока управляют физическими фигурками на зелёном поле и пытаются забить мяч в ворота соперника. Физика делает движения непредсказуемыми и весёлыми.

## Как управлять?

### Игрок 1 (Синий)
- **W** — прыжок
- **A** — влево
- **D** — вправо

### Игрок 2 (Красный)
- **↑** — прыжок
- **←** — влево
- **→** — вправо

### Общее
- **Пробел** — начать игру
- **ESC** — пауза

### Мобильные устройства (тач-экран)
Игра ориентирована на **горизонтальный** экран: в портретном режиме
показывается подсказка «Поверните устройство», а игра встаёт на паузу.

- **Джойстик слева** — появляется при касании левой половины экрана, управляет Игроком 1:
  отклонение влево/вправо — движение, отклонение **вверх** — прыжок
- **Джойстик справа** — то же самое для Игрока 2 (правая половина экрана)
- **⏸** (правый верхний угол) — пауза; на экране паузы есть кнопка «ПРОДОЛЖИТЬ»

> Отладка на десктопе: откройте игру с параметром `?touch=1` —
> мобильный интерфейс включится принудительно, без тач-экрана.

## Что должен делать игрок?

1. Управлять своим персонажем
2. Пинать мяч в ворота противника
3. Забить больше голов за 60 секунд
4. Победить соперника

## Что пока не реализовано?

- Звуковые эффекты
- Анимации голов и побед
- Настройка времени матча
- Различные режимы игры

## Аналитика (Яндекс Метрика)

Счётчик `114691798` подключён в `index.html`, отправка целей — через `src/metrics.ts`.

| Название цели в Метрике | Идентификатор цели | Когда срабатывает |
|---|---|---|
| Начал матч | `match_start` | Нажата кнопка «Начать» или пробел |
| Забит гол | `goal_scored` | Гол засчитан (параметры: `scorer`, `phase`, `total`) |
| Матч доигран | `match_finished` | Таймер дошёл до нуля (параметры: `p1`, `p2`) |
| Играть снова | `rematch` | Нажата кнопка «Играть снова» |
| Достигнута фаза | `phase_reached` | Переход в фазу 2, 3 или 4 (параметр `phase`) |

В интерфейсе Метрики цели создаются как **Целевое событие** с режимом сравнения «Совпадает»: в поле «Идентификатор цели» вписывается значение из таблицы (латиницей, без кавычек).

- На `localhost` счётчик не инициализируется, чтобы не засорять статистику. Для отладки откройте игру с параметром `?ym=1`.
- Цели не восстанавливаются задним числом: создайте их в Метрике до публикации сборки с вызовами.
